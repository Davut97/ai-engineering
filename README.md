# AI Engineering

My 20-week plan to move into an AI engineer role (Oct 19, 2026 to Mar 7, 2027).

- Roadmap and progress tracker: https://claude.ai/code/artifact/d9375328-487b-4578-a01e-5cb1ae526a75
- Weekly log: [PROGRESS.md](PROGRESS.md)

## Structure

| Folder | What goes in it | Weeks |
|---|---|---|
| `00-chat-app/` | Week 1 chat app: FastAPI + Next.js, streaming, one tool | 1 |
| `01-document-extractor/` | Project 1: PDFs to validated JSON, field-level evals | 2 to 3 |
| `02-rag-qa/` | Project 2: cited Q&A over documents, eval suite | 5 to 8 |
| `03-sql-agent/` | Project 3: SQL analyst agent + MCP server | 10 to 12 |
| `04-fine-tuned-extractor/` | Project 4: fine-tuned open model vs frontier model | 15 to 16 |
| `capstone/` | Optional: a real AI feature with real users | 12 onward |
| `notes/` | Learning notes, one file per topic (e.g. `notes/embeddings.md`) | all |

## Rules for every project

- Deployed at a public URL
- At least one eval number in the README, and how it changed
- Real data, not the tutorial default
- A short write-up of one decision and what I measured
